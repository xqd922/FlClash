# XClash v0.8.94 合并前修改逐项审计

## 审计基线

- 共同基线：`672eacc`
- 合并前最终版本：`backup/optimize-pre-v0.8.94-20260713`（`9e87fb6`）
- 当前架构：上游 v0.8.94
- 原则：合并前最终产品行为优先；旧控制器、旧生成文件和已相互抵消的中间实现不直接恢复。

## 分类说明

- **精简**：主动删除入口、状态或视觉噪声，必须继续保持。
- **修改**：品牌、默认值、配置优先级等产品语义，在新架构上重做。
- **优化**：性能、内存、电量和稳定性改进，保留需求并适配新实现。
- **丢弃**：临时实验、后续回滚、中间实现或已经被新版架构替代的代码。

## 本轮新增修复

- 完整删除被误恢复的复杂主题项及其死代码。
- 恢复自动色默认值，而不是空列表下仍强制粉色。
- 恢复 Android 独立包名和 XClashHelperService 全链品牌。
- 恢复 IP 刷新去 Dashboard 门槛、Profile UI 字段、网络接口筛选和代理 Tab 固定边距。
- 恢复 Core 构建标签、低内存 ABI、MTU、图片缓存、Go 构建参数、FlutterEngine 复用、网络切换断连和配置后 GC。

## 后续合并规则

1. 不得按提交标题过滤 Release 提交；多个 Release 提交夹带真实产品修改。
2. 先读取合并前最终 `RELEASE.md`，再逐提交核对实现。
3. 旧实现可以丢弃，但其产品语义必须在新架构上有明确替代。
4. 任何标为精简的内容，默认禁止因上游新增能力而重新出现。
